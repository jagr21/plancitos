# 🌴 Plancitos para el Fin

> Feed minimalista para descubrir y organizar actividades para el fin de semana.

Aplicación web moderna diseñada para uso personal. Permite catalogar opciones de esparcimiento, ordenadas por presupuesto, logística y categorías, integrando elementos visuales dinámicos.

---

## ✨ Características Principales

* **Autenticación Privada:** Sistema de Login y Registro nativo e instantáneo gestionado por **Supabase Auth**.
* **Base de Datos en Tiempo Real:** Los planes se guardan de forma inmediata en una base de datos **PostgreSQL (Supabase)**, filtrando el contenido para que cada usuario gestione sus propias opciones.
* **Buscador de Imágenes Integrado:** Conexión directa con la API de **Unsplash** para buscar y seleccionar fotos desde el mismo formulario.
* **Diseño Ultra-Moderno:** Interfaz móvil (*mobile-first*), limpia y minimalista maquetada con **Tailwind CSS**.
* **Filtros Inteligentes:** Clasificación rápida por categorías (Gastronomía, Outdoor, Aventura) y rangos de presupuesto ($, $$, $$$).

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3 (Tailwind CSS vía CDN), JavaScript Vanilla (ES6+).
* **Backend & Base de Datos:** Supabase (PostgreSQL, Realtime y Auth).
* **APIs Externas:** Unsplash API (Buscador de imágenes).
